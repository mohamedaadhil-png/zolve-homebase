# Zolve Home Base

A Next.js job platform for H-1B visa sponsorship tracking. Helps international professionals find software engineering roles at companies with verified sponsorship history, backed by USCIS and DOL government data.

## Tech Stack

- **Framework**: Next.js 14 App Router (TypeScript)
- **Styling**: Tailwind CSS + Plus Jakarta Sans
- **Backend**: Supabase (Auth, Postgres, Storage)
- **Deployment**: Cloudflare Pages via `@cloudflare/next-on-pages`
- **AI**: Anthropic Claude (resume parsing)

## Local Development

### Prerequisites

- Node.js 20+
- Supabase CLI (`npm install -g supabase`)
- Wrangler CLI (included as dev dependency)

### Setup

1. Clone the repo and install dependencies:

```bash
npm install
```

2. Copy the environment file and fill in your values:

```bash
cp .env.local.example .env.local
```

3. Start the local Supabase stack:

```bash
supabase start
```

4. Apply database migrations:

```bash
npm run db:migrate
```

5. (Optional) Seed the database:

```bash
npm run seed
```

6. Start the dev server:

```bash
npm run dev
```

The app will be available at `http://localhost:3000`.

## Database Commands

```bash
# Push local migrations to Supabase
npm run db:migrate

# Reset local database (destructive)
npm run db:reset
```

## Data Pipeline Commands

```bash
# Seed companies and jobs from staging fixtures
npm run seed

# Validate Greenhouse ATS integration
npm run validate:greenhouse

# Validate USCIS/DOL government data ingestion
npm run validate:gov-data
```

## Cloudflare Pages Deployment

1. Build the Cloudflare-compatible output:

```bash
npm run pages:build
```

2. Preview locally with Wrangler:

```bash
npm run preview
```

3. Deploy to Cloudflare Pages:

```bash
npm run deploy
```

Ensure `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` are set before deploying.

## Supabase Auth (Google OAuth)

Google OAuth credentials are configured directly in the Supabase dashboard under **Authentication > Providers > Google**. No additional env vars needed in the app — Supabase handles the OAuth flow.

## Architecture Notes

### Sponsorship Data Pipeline

- **USCIS I-129 data** (initial/continuing H-1B approvals and denials by employer) is ingested into `uscis_sponsor_records`.
- **DOL LCA disclosure data** is ingested into `dol_lca_records`.
- Both tables are fuzzy-matched and linked to `companies` via `normalized_name`.
- Each company gets a computed `sponsor_score` (0–100) and `approval_rate` derived from USCIS records.

### Job Ingestion

- Jobs are pulled from company ATS boards (Greenhouse, Lever, Ashby) and stored in `job_postings`.
- `company_aliases` handles name variations across data sources.
- `is_active` is set to `false` when a posting is no longer found on the ATS board.

### User Profiles

- Auth is handled by Supabase (Google OAuth).
- Extended profile data lives in `users`, `user_education`, and `user_employment`.
- `user_profile_completion` is a computed view updated on profile save.
- `visible_to_employers` controls recruiter discovery.

### Deployment Architecture

- Cloudflare Pages hosts the static/edge output generated by `@cloudflare/next-on-pages`.
- Supabase is the sole backend — no separate API server.
- All server-side logic runs in Next.js Route Handlers and Server Components at the edge.
